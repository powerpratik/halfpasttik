<h1>Privacy policy</h1>
<p>Last updated: November 14, 2026</p>
<p>This policy covers the Half Past Tik uploader, a private tool used only by the owner of the Half Past Tik YouTube channel to upload that channel's own videos.</p>
<h2>What it accesses</h2>
<p>With the channel owner's permission, the tool uses Google's YouTube Data API scopes youtube.upload and youtube.force-ssl to upload videos, set thumbnails and add captions to the owner's own channel, and to confirm which channel it is signed in to.</p>
<h2>What it stores</h2>
<p>The sign-in token is stored only on the owner's own computer, in the operating system's keychain. A local record of uploaded video IDs is kept on that computer to avoid duplicate uploads. Nothing is sent to any server other than Google's.</p>
<h2>What it does not do</h2>
<p>It does not collect, sell or share data about viewers or any other person, and it does not use Google user data for advertising or any purpose other than uploading the channel's own content.</p>
<h2>Google API Services</h2>
<p>The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.</p>
<h2>Revoking access</h2>
<p>Access can be revoked at any time at myaccount.google.com/permissions.</p>
